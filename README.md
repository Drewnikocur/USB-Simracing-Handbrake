# USB-Simracing-Handbrake

Open-Source USB Simracing Handbrake

An open-source, 3D-printable USB simracing handbrake designed for rally and drift games (such as Assetto Corsa, BeamNG.drive, and Richard Burns Rally). It features a robust desk clamp, an ergonomic lever, and smooth analog input powered by an ESP32 and a 10k potentiometer. Easy to print, assemble, and set up with the included Python vJoy bridge script.
